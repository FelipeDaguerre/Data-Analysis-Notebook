Exemplo de Prompts:
P: Qual a diferença entre SQL e NoSQL, e onde seria uma opção melhor usar cada um deles?

R: * **Bancos de dados SQL (Relacionais)**:
  * Utilizam a linguagem de consulta estruturada (*SQL*) para interagir com a base de dados[1].
  * São desenhados para **dados estruturados**, exigindo um esquema (*schema*) rígido e pré-definido no qual cada elemento de informação está organizado em campos fixos e tabelas[2][4].
  * Oferecem simplicidade na pesquisa, inserção e análise de informações altamente organizadas[3].
* **Bancos de dados NoSQL**:
  * São otimizados para armazenar e gerir **dados semiestruturados** (como ficheiros JSON e XML) e dados não estruturados de forma mais eficiente do que as bases relacionais tradicionais[5][6].
  * Proporcionam flexibilidade de estrutura (*schema-on-read*), adaptando-se a formatos diversos e em constante evolução[5][6]

### Quando usar cada um?

* **Melhor opção para SQL**:
  * Quando a aplicação trabalha com **dados estruturados** e bem definidos, nos quais a informação segue uma estrutura padronizada — como registos financeiros de transações, dados de recursos humanos ou informações de clientes em sistemas CRM[3][4].
* **Melhor opção para NoSQL**:
  * Quando a aplicação lida com grande **variedade e diversidade de dados** (como dados semiestruturados da web, sensores IoT, logs de sistema ou conteúdos multimédia) que exigem um modelo flexível e não fixo[5][6].
